# Трекер задач

Одностраничный трекер задач по проектам. Работает прямо в браузере без сервера, библиотек и сборки.

## Что умеет

- Добавить задачу ([спецификация](specs/001-добавить-задачу.md)).
- Показывать итоги по проектам ([спецификация](specs/002-итоги-по-проектам.md)).
- Удалить задачу ([спецификация](specs/003-удалить-задачу.md)).
- Вести контракты с лимитом часов ([спецификация](specs/004-контракты-с-лимитом-часов.md)).

## Как открыть и проверить

1. Открыть `index.html` в браузере.
2. Создать контракт «Поддержка сайта» с лимитом `10` ч.
3. Проверить карточку контракта: лимит `10 ч`, в задачах `0 ч`, осталось `10 ч`.
4. Попробовать создать контракт с лимитом `0`, затем `0,3`: оба раза контракт не добавляется и показано сообщение об ошибке.
5. Добавить задачу «Исправить меню»: проект «Альфа», срок `27.11.2026`, оценка `3,5`, статус «В плане», контракт «Поддержка сайта».
6. Проверить, что у задачи показаны срок `27.11.2026`, оценка `3,5 ч` и контракт «Поддержка сайта».
7. Проверить карточку контракта: лимит `10 ч`, в задачах `3,5 ч`, осталось `6,5 ч`.
8. Добавить в проект «Альфа» в тот же контракт задачу на `7,5` ч и проверить: в задачах `11 ч`, превышение `1 ч`.
9. Добавить в проект «Альфа» задачу на `2` ч с вариантом «Без контракта» и проверить, что показатели контракта не изменились.
10. Нажать «Удалить» у задачи на `7,5` ч и проверить: в задачах `3,5 ч`, осталось `6,5 ч`.
11. Проверить итог проекта «Альфа»: `3 задачи`, всего `13 ч` до удаления и `2 задачи`, всего `5,5 ч` после удаления.
12. Нажать F5 и проверить, что контракт, две оставшиеся задачи, связь задачи с контрактом и все показатели сохранились.
13. Открыть консоль браузера клавишей F12 и убедиться, что красных ошибок нет.
## Правила для агента

Правила лежат в файле [AGENTS.md](AGENTS.md).

Правило, добавленное после ошибки: в разделе «Что умеет» ровно одна строка на каждую функцию, и в каждой строке есть ссылка на её файл в specs/.

Какая была ошибка: агент обновил README, но написал шесть пунктов без ссылок на спецификации. По заданию нужны три функции со ссылками.

## Отчёт

Какое правило сработало сразу: правило «Новая функция». Агент с первого раза создал файл в specs/ и не стал писать код, пока я не написал «Делай по».

Какое правило не сработало: правило про обновление README. В нём было сказано только «обнови разделы», и агент оформил их по-своему.

Как я его переписал: добавил, что на каждую функцию одна строка со ссылкой на файл в specs/, и дал пример строки. После этого в новом чате агент переписал раздел правильно.
