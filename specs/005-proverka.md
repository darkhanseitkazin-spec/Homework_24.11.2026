# Проверка проекта

[x] В `README.md` шаг 11 нельзя однозначно повторить: для второй и третьей задач не указан проект «Альфа», хотя итог проверяется именно для этого проекта.

[ ] Данные из `localStorage` проверяются только на то, что это массив. Если сохранённая задача не содержит срока или оценки, страница падает при отрисовке вместо показа остальных корректных данных.
