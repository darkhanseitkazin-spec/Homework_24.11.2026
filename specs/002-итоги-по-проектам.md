# Итоги по проектам

## Что делаем

Добавляем на страницу итоги отдельно для каждого проекта. Итоги рассчитываются по всем задачам проекта и показывают количество задач, общую оценку в часах, количество часов по готовым задачам и количество оставшихся часов.

Готовыми считаются задачи со статусом «Готово». Оставшиеся часы — сумма оценок задач со статусами «В плане» и «В работе».

## Как это выглядит

На странице появляется блок «Итоги по проектам». Для каждого проекта, который встречается в списке задач, показана отдельная строка или карточка с:

- названием проекта;
- количеством задач;
- общей суммой часов по всем задачам проекта;
- суммой часов по задачам со статусом «Готово»;
- суммой часов по задачам со статусами «В плане» и «В работе».

Часы отображаются с запятой и суффиксом «ч», например «3,5 ч». Итоги обновляются сразу после изменения списка задач и правильно восстанавливаются после перезагрузки страницы.

## Примеры
- Проект «Альфа»: задачи на 2 ч («Готово»), 1,5 ч («В работе»), 4 ч («В плане»). Итог: 3 задачи, всего 7,5 ч, готово 2 ч, осталось 5,5 ч.
- Добавляю в «Альфа» ещё задачу на 0,5 ч. Итог сразу меняется: 4 задачи, всего 8 ч.
- Задач нет. Вместо итогов надпись «Задач пока нет».
## Готово, когда

- На странице виден блок «Итоги по проектам».
- Для каждого проекта из списка задач в блоке показано его название.
- Для каждого проекта показано точное количество его задач.
- Для каждого проекта общая сумма часов равна сумме оценок всех его задач.
- Для каждого проекта готовые часы равны сумме оценок задач со статусом «Готово».
- Для каждого проекта оставшиеся часы равны сумме оценок задач со статусами «В плане» и «В работе».
- Для каждого проекта сумма готовых и оставшихся часов равна общей сумме часов.
- Каждая сумма часов отображается с запятой и суффиксом «ч», например «3,5 ч».
- После добавления новой задачи итоги соответствующего проекта обновляются без перезагрузки страницы.
- После нажатия F5 задачи и рассчитанные по ним итоги не пропадают.
- В консоли браузера нет красных ошибок.
