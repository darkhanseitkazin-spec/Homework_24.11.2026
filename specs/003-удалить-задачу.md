# Удалить задачу

## Что делаем

Добавляем возможность удалить любую задачу из списка. После удаления задача исчезает из списка, изменение сохраняется в localStorage, а итоги по проектам сразу пересчитываются по оставшимся задачам.

## Как это выглядит

У каждой задачи в списке есть кнопка «Удалить». При нажатии на неё удаляется только выбранная задача. Страница не перезагружается.

Если удалена последняя задача проекта, этот проект больше не показывается в итогах по проектам. Если удалена последняя задача во всём списке, отображается предусмотренное для пустого списка состояние, а вместо итогов — надпись «Задач пока нет».

## Примеры
- В проекте «Альфа» задачи на 2 ч, 1,5 ч и 4 ч, всего 7,5 ч. Удаляю задачу на 4 ч. В списке остаются две задачи, итог: всего 3,5 ч.
- Удаляю задачу и нажимаю F5. Удалённая задача не возвращается.
- Удаляю последнюю задачу проекта. Проект исчезает из итогов.
## Готово, когда

- У каждой задачи в списке видна кнопка «Удалить».
- Нажатие кнопки «Удалить» удаляет именно ту задачу, у которой была нажата кнопка.
- После удаления задача сразу исчезает из списка без перезагрузки страницы.
- После удаления количество задач соответствующего проекта в итогах уменьшается на 1.
- После удаления общая сумма часов соответствующего проекта уменьшается на оценку удалённой задачи.
- Если удалена задача со статусом «Готово», сумма готовых часов соответствующего проекта уменьшается на её оценку.
- Если удалена задача со статусом «В плане» или «В работе», сумма оставшихся часов соответствующего проекта уменьшается на её оценку.
- Если удалена последняя задача проекта, проект исчезает из итогов по проектам.
- Если удалена последняя задача во всём списке, отображается состояние пустого списка и надпись «Задач пока нет» вместо итогов.
- После нажатия F5 удалённая задача не появляется снова, а оставшиеся задачи и итоги сохраняются.
- В консоли браузера нет красных ошибок после удаления задачи.
