# AGENTS.md

## О проекте
Трекер задач по проектам. Одна страница в браузере.
Файлы: index.html, styles.css, script.js.
Данные хранятся в localStorage браузера. Сервера нет.

## Правила
1. Только HTML, CSS и JavaScript. Без библиотек, фреймворков и сборки.
2. Весь текст интерфейса на русском языке.
3. Срок задачи показывается в формате ДД.ММ.ГГГГ. Пример: 27.11.2026.
4. Оценка в часах: число больше 0 с шагом 0,5. На экране с запятой: 1,5 ч, а не 1.5.
5. Статус задачи только один из трёх: «В плане», «В работе», «Готово».
6. После каждого изменения данные сохраняются в localStorage. После F5 все задачи на месте.
7. За один раз делается одна функция. Код, который к ней не относится, не меняется.
8. Коммиты делаю я сам. Агент команду git commit не выполняет.

## Новая функция
Когда я пишу «Новая функция: ...»:
1. Код не пиши.
2. Создай файл specs/00N-короткое-название.md, где N это следующий номер по порядку.
3. В файле четыре раздела: «Что делаем», «Как это выглядит», «Примеры», «Готово, когда».
4. Раздел «Примеры» оставь пустым, я заполню его сам.
5. В разделе «Готово, когда» каждый пункт можно проверить: да или нет.
6. Остановись и жди. Код пиши только после команды «Делай по @specs/...».

## Как проверить
1. Открыть index.html в браузере.
2. Пройти по порядку все пункты «Готово, когда» из файла спецификации.
3. Нажать F5 и убедиться, что данные не пропали.
4. Открыть консоль браузера (F12) и убедиться, что там нет красных ошибок.
